## Addendum - Control B verified: no orphan or isolated table (I3)

A per table foreign key audit on the real database was run. Initially `audit` was
the only isolated table (no incoming or outgoing FK), matching the DAT audit DDL
which omits the actor FK. The DAT relations section declares "utilisateur 1 to N
audit", so migration 0006 adds `audit.acteur_id -> utilisateur(id)` ON DELETE NO
ACTION (append-only preserved; see ADR-0003).

Live result after migration 0006:

```
Tables isolees/orphelines: AUCUNE (les 18 tables sont liees)
```

Every one of the 18 tables now participates in at least one coherent relation
(membre has 1 outgoing and 9 incoming FK, utilisateur 1 and 7, and so on). An
offline test (`test_no_orphan_or_isolated_table`) enforces this going forward.
Per role RLS (35 policies, 18 tables) was also added and verified (5/5 roles),
see ADR-0002.
